# MTA:SA Docker Image

MTA:SA Server with FastDL and MySQL support - Powered by Trident Sky

## Features

- Nginx for FastDL
- MySQL client libraries
- Based on Pterodactyl Yolks Ubuntu base
- Automatic builds via GitHub Actions

## Usage

Use this image in your Pterodactyl egg:
```
ghcr.io/tridentskyy/mta-fastdl:latest
```
